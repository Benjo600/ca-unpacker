1 · Right now

now

Finish what you started today.

  • First real publish + popup test
    Sign into the dashboard → New features → Create release draft on v0.11.2 → install that exe, run one job → publish → confirm an old install pops Install now / Later and completes a silent update.
    5 min of clicks
  • CI installers ship without Tesseract — OCR silently missing
    The CI runner has no Tesseract, and bundle_tesseract.py exits 0 when it's missing. So v0.11.1 / v0.11.2 (and every future auto-build) have no OCR — scanned bank PDFs would return nothing on a customer PC. Fix: choco install tesseract-oss (or download a pinned release) in the workflow before bundling, and fail the build if tessdata/eng.traineddata is absent.
    highest impact fix
