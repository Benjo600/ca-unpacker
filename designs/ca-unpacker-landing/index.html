Workflow

How a period runs

Create a client, open a month, dump the mixed folder. The app copies files into a private library, labels them, and writes Excels to the folder you chose on first launch.

  1. Install once. Double-click Setup. Start menu and optional desktop shortcut appear. No account.
  2. Name the firm and the Excel folder. Originals stay under %LOCALAPPDATA%\CAUnpacker\. Cleaned packs go where you point.
  3. Add client → add period. Dump belongs to a month, so twelve months can live side by side.
  4. Drop the mess. PDFs, JSON, zip, CSV, JPG, PNG. Do not pre-label. Unknown files sit in Needs review; you can override the type and re-run.
  5. Take the pack. Open in Excel, or click a debit/credit/GSTIN in the tray to see the crop from the original page.

What it unpacks

Four specialist paths

The classifier only chooses a parser. It never extracts amounts. Each parser owns its schema and flags. It does not silently “fix” GSTINs or balances.

01 Bank

Statement → checked Excel

Digital HDFC, ICICI and SBI PDFs become Bank_Statement_Cleaned.xlsx with a balance-check sheet: stated close versus running total, match or mismatch. Source column carries the page.

02 Invoices

Bills → purchase register

Printed PDF or image tax invoices write Purchase_Register_Extracted.xlsx. GSTIN checksum, HSN length (4/6/8) and invoice arithmetic are flagged, never rewritten. Unreadable photos stay unknown.

03 GST portal

Ugly JSON → readable sheets

Official GSTR-1, GSTR-2B and GSTR-3B JSON downloads become formatted workbooks. No GST portal login. When books or invoices are in the same period, the master grid fills match status.

04 Books

Tally / Zoho without opening them

Tally XML or zip daybook, and Zoho Books CSV, become purchase and sales registers in the same field shape as invoices so the 2B join can match them. Live Tally ODBC is out of scope.

05 Trust

Click a number, see the page

Extracted rows keep page and region. Click a debit, GSTIN or amount in the app to see a crop from the original. Password PDFs prompt once; the password is not saved.

06 OCR

Scans stay on the laptop

Tesseract ships in the installer. Scanned statements and invoice photos never go to a cloud OCR vendor. Weak scans are flagged or left for review rather than invented.

The pack

Same filenames every period

Excel is the takeaway. The app is where you verify. Source pointers stay on the row.

Written when present

  • Bank_Statement_Cleaned.xlsx
  • Purchase_Register_Extracted.xlsx
  • Sales_Register_Extracted.xlsx
  • Books_Register_Extracted.xlsx
  • GSTR_1_Formatted.xlsx · GSTR_2B_Formatted.xlsx · GSTR_3B_Formatted.xlsx
  • Master_Reconciliation_Grid.xlsx

Not this build

  • Live GST portal login or e-filing
  • Live Tally company / write-back
  • ITR, 26AS, salary slips, contracts
  • Mobile app or cloud document store

Privacy

Client files never leave the PC

Indian firms will not put a month of statements on someone else’s server. Local processing is the product.

No upload

PDFs, JSON, XML and images stay on disk. There is no cloud OCR and no portal scrape.

Validate, don’t edit

Bad GSTIN, odd HSN, broken invoice maths, balance mismatch — flagged. Source numbers are not silently rewritten.

Needs review

Unknown files are listed, not guessed. Recognised files that extract nothing show a reason in the tray.
